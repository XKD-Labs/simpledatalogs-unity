# Security policy

## Reporting a vulnerability

Please report security issues privately, never in a public issue.

- Use GitHub's private reporting: the **Security** tab of [XKD-Labs/simpledatalogs-unity](https://github.com/XKD-Labs/simpledatalogs-unity/security/advisories/new) → "Report a vulnerability".
- Or email **mail@xkdlabs.com**.

Include the package version, the Unity version and player platform, what you found and how to reproduce it. We aim to answer within 3 working days and to ship a fix for confirmed issues as soon as we can.

## Supported versions

Fixes go into the latest release. Upgrade to it before reporting.
